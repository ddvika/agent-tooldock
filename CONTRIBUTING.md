# Как дополнить Agent ToolDock

Предлагайте изменения через pull request или форму issue **Добавить или обновить подключение**. Для каждого сервиса и протокола нужна отдельная запись в `data/catalog.json`.

## Добавить или исправить подключение

Укажите ID существующей записи или предложите новый уникальный ID. Приложите первичный источник, дату проверки и условия доступа. Описывайте функции, которые подтверждаются источником.

Сохраняйте различия между следующими характеристиками.

- API владельца сервиса и сторонний коннектор.
- Возможности покупателя и продавца.
- Чтение информации, подготовка и выполнение действия.
- Выставление счёта и проведение платежа.
- Функция из документации и результат реального теста.

Укажите регистрацию, платный план, договор, OAuth и ограничения, если они входят в условия. При недостатке сведений заполните ограничения и оставьте соответствующую возможность неподтверждённой. Для нового поля обновите описание структуры и проверки.

## Проверить изменение

```sh
npm run export
npm test
npm run demo
```

CSV генерируется из JSON. Вместе с исходными данными включите обновлённый CSV в pull request.

Тесты текущего среза фиксируют количество записей и результаты контрольных запросов. При добавлении записей или обновлении среза пересчитайте показатели в README и обновите соответствующие ожидаемые значения тестов. В описании pull request покажите изменение состава данных и подтверждающие источники. Проверки корзины, оформления заказа и оплаты должны сохранять смысл.

При изменении кода также проверьте упаковку.

```sh
npm pack --dry-run
```
